
# 🐍 Selamat Datang di Snake Game!

Game ini merupakan implementasi Project-Based Learning (PJBL) yang berhasil kami kembangkan.

## Petunjuk Permainan

* *SPACE* → Memulai permainan
* *Tombol Panah (↑ ↓ ← →)* → Mengarahkan pergerakan ular
* *P* → Menjeda permainan (*Pause*)
* *R* → Mengulang permainan (*Restart*)

## Panduan Level dan Skor

* *Level 1:* Skor 0 – 21
* *Level 2:* Skor 22 – 31
* *Level 3:* Skor 32 – 41
* *Level 4:* Skor 42 – 51
* *Level 5:* Skor 52 ke atas

## Aturan Khusus Level 5

Pada Level 5, ular *tidak dapat menembus dinding*. Jika ular menabrak dinding, permainan akan berakhir (*Game Over*).

## Bonus Food
* Muncul secara acak di arena permainan.
* Memberikan +5 skor.
* Akan menghilang setelah 7 detik jika tidak dimakan.

## Tujuan Permainan

Makan makanan untuk menambah skor dan naik ke level berikutnya. Semakin tinggi level, kecepatan ular akan semakin meningkat sehingga permainan menjadi lebih menantang.

*Tekan SPACE untuk memulai permainan!*
